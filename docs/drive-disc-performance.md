# 驱动盘仓库加载与展示优化

## 行为

- 仓库每页显示 5 张盘，公共选盘弹窗和工作台旧选盘弹窗每页 10 张。搜索和筛选针对完整库存，结果变化回到第一页；批量导出和优化候选不受分页影响。
- 套装预设支持按代理人筛选，一次渲染所选角色的全部预设；默认显示当前账号的全部预设，选项包含未知角色和公共预设。保存后自动显示保存的角色。筛选不改变盘的专属、排除和穿戴关系。
- 卡片模式预设编辑器也提供名称、角色输入；新增预设默认属于当前选择的角色。
- 只缓存最近一个账号的仓库页，其他页面沿用原有生命周期。离开仓库时关闭弹窗并卸载弹窗轮询；返回保留筛选和代理人选择。槽位筛选使用普通按钮，保留键盘访问和局部横向滚动。
- 库存视图只在账号相同、没有读取错误或加载任务、视图未替换且没有库存写入时复用。写入开始和结束均使缓存失效，包括失败写入。旧加载响应不会覆盖新响应。
- 其他浏览器标签页的修改需要点“刷新”；刷新始终读取最新存储。缓存仅驻留内存，不改变存储格式。
- 正式目录已有的 `scanner-set-*` 编号不重复触发别名迁移与写回；按账号过滤时复用已规范化数据，避免重复指纹计算。

## 验证入口

- `node tests/drive-disc-import.test.js`：套装编号迁移幂等。
- `webapp/src/stores/local-store-indexeddb-compat.test.ts`：重复读取不写回、读取后的账号隔离。
- `webapp/src/stores/inventory-cache.test.ts`：缓存复用、刷新、写入失效、失败和请求/账号隔离。
- `webapp/src/views/DiscsView.test.ts`：5 张分页、全量搜索、代理人过滤、未知/公共角色、保存后显示对应预设。
- `webapp/src/components/DriveDiscPickerModal.test.ts`：选盘分页与完整库存搜索。

浏览器验收包括分页、预设切换、编辑保存回读、切账号、离开仓库关闭弹窗、导出范围以及桌面/窄屏布局。
性能结果应注明库存规模、预设数量、测量区间与次数，不能把本地综合版本的测量直接视为本 PR 相对上游的收益。
