# 简·杜主控与潜能影像建模

资料来源：[官方条目759](https://baike.mihoyo.com/zzz/wiki/content/759/detail?mhy_presentation_style=fullscreen)，修订 `1788063783`，2026-10-08读取。
[来源fixture](../tests/fixtures/jane-source-values.json)保存普通与潜能技能逐级数据、核心/潜能成长、影画原文及格式清洗记录。

## 计算边界

默认是一次失衡状态的普通物理强击，`mode: custom`、`settlementType: attribute`、`anomalyEffect: assault`、`count/procCount: 1`。
核心F、首次潜能P6，核心与额外能力默认启用；显式选择P0会保存并跨刷新保留。P0-P6均能选择已录入的潜能招式，潜能数值读取各自档位。

采用狂热与啮咬条件成立的状态快照，允许关闭Buff或逐规则调整覆盖率。
“普通攻击｜狂热”是默认启用的独立技能来源Buff，负责精通转攻击；“核心被动：洞察”只负责啮咬、畏缩延长与强击暴击。两者可以分别关闭。
狂热心流、动作时长、能量、异常积蓄效率和触发顺序只保留机制说明，不推导自动事件或伤害加成。
六影官方追加攻击说明保留在角色资料中；暴击率与暴击伤害按当前结算规则生效。

## 面板与效果

60级初始面板（不含核心节点）：生命7788、攻击805、防御606、冲击86、暴击率5%、暴击伤害50%、异常掌控112、异常精通114、能量自动回复1.2、穿透率0。
项目JSON中的能量回复存储为120，运行时为1.2。A/C/E各加12异常掌控，B/D/F各加25基础攻击力；核心F裸角色攻击880、掌控148。

以当前局内异常精通 `P` 计算：

| 效果 | 公式及目标 |
| --- | --- |
| 狂热攻击力 | `clamp(max(P - 120, 0) * 2, 0, 600)`，加入局内固定攻击力 |
| 核心强击暴击率 | `clamp((基础暴击率 + P * 核心系数) / 100, 0, 1)`；只针对属性异常强击 |
| 核心强击暴击伤害 | 50%；普通直伤暴击面板不变 |
| 核心畏缩延长 | 畏缩紊乱持续时间增加5秒；不把强击次数增加为多次 |
| 潜能强击暴击伤害 | P0/P1为0，P2-P6为10/15/20/25/30%；通过自身额外能力的潜能成长规则启用 |
| 一影狂热增伤 | `clamp(max(P - 120, 0) * 0.1, 0, 30)%`，普通增伤区，420精通达到上限 |
| 二影 | 计算强击的15%无视防御和50%异常暴击伤害；简直伤对啮咬目标的无视防御部分不进入本次默认强击目标 |
| 四影 | 默认作用域属性异常增伤18%，按既有结算规则读取；不进入紊乱增伤区 |

核心初始/A-F的基础暴击率为20/25/28/31/34/37/40%，每点精通系数为0.10/0.11/0.12/0.13/0.14/0.15/0.16%。
一影与狂热攻击力转换共用120点异常精通起算门槛；每超过1点提升0.1%自身伤害，420点达到30%上限。该规则按当前确认的实际机制建模，官方来源原文仍保留在来源fixture中。
潜能页面注明10/15/20/25/30为满核心数值，本次按选定快照沿用这些值，不猜测官方未给出的低核心潜能缩放。

三影、五影保存技能加级说明，技能输入为最终等级，不重复加级。

## 技能目录与维护

完整保留16组官方逐级技能资料及2个同倍率的潜能强化选择，共18个招式、58行伤害/失衡/能量数据。
招架只有失衡行，不能进入伤害事件；萨霍夫跳连续攻击和终结一击分开；潜能第六段单独保留普通攻击类型和冲刺标签，避免把前五段也当作冲刺攻击。
潜能掠空横扫与狂热强袭同时带 `exSpecial`、`dashAttack`，基础版横扫仅带 `exSpecial`。
官方潜能萨霍夫跳Lv11的四项倍率漏写百分号，按倍率列单位读取原数字，没有外推或更改数值。

提供七个可重复技能组：普攻六段、基础/潜能萨霍夫跳、基础/潜能强化特殊技、连携技、终结技。
各组明确自己的子事件，没有隐藏强击次数或附带六影攻击。维护的默认目标与技能组分别保存。

推荐獠牙重金属四件套；4号位比较异常精通/攻击，5号位物理伤害/攻击/穿透率，6号位掌控/攻击。两件套不限制。
掌控在本单次强击目标下不直接增加伤害，不表示其积蓄收益无效；积蓄时间在本次范围之外。
重要副词条为攻击百分比/异常精通，重要面板为攻击/精通/掌控，仅影响展示。

狂热的来源引用绑定普通攻击目录，省略 `sourceSkillRef.moveId`，维护页显示“整个技能目录”；没有虚构招式或倍率行。
旧浏览器配置首次读取时，狂热继承原核心的实际启用状态，并迁移原攻击转换规则的覆盖率；已有狂热选择和运行时配置优先。
每个简配置保存 `combat.janeFrenzySplitVersion: 1`，之后核心与狂热的独立选择不再联动。一影继续是独立的影画快照Buff，不随狂热开关自动变化。
