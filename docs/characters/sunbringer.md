## 测试服改数入口

更新技能倍率时，将新版 Nanoka 角色 JSON 按版本保存到 [来源目录](../sources/)，同步 [招式倍率表](../../data/agent_skills.json) 中挽昼的数值和来源版本，再运行 `npm run test:sunbringer`。测试会用对应版本的原始数据逐招核对所有等级。核心、影画和烬痕系数在 [角色配置](../../data/agents.json) 的 `sunbringer` 条目，参考轴也在该条目的计算配置中。专武五档数值在 [音擎配置](../../data/w_engines.json) 的 `dragonfire_mirage` 条目。

## 默认计算目标

工作台计算挽昼的个人伤害。0、1 影使用单投一轮；2 影起使用双投接单投的两轮参考轴，参考用时 90 秒。两轮轴取自 2+1 挽昼的既有配队实战记录，保留其中的挽昼动作，队友增益默认关闭。更高影画沿用同一轴便于对比。总伤害除以实际用时可得到每秒伤害。

| 阶段 | 参考动作 |
| --- | --- |
| 常规失衡前 | 斩棘完整四段 ×3、支援突击「不灭热忱」×3、晦尽（改）×2、曦生（改）×1 |
| 0、1 影单投轮 | 投枪 → 此行 → 连携 → 黄星 → 连携 → 晦尽（改）→ 此愿 |
| 两轮轴的第一轮 | 常规失衡前。失衡内投枪 → 黄星 → 红星 → 连携 → 投枪 → 此行 → 此愿 |
| 两轮轴的第二轮 | 常规失衡前加一次黄星。失衡内投枪 → 黄星 → 连携 → 此行 → 连携 → 晦尽（改）→ 此愿 |

投枪指「执旌·聚锋」，黄星按「焚夜·长暗终焉」建模，红星指「燃灯·永昼之炬」。第一轮双投共 6 次毁伤，3 次在失衡内。第二轮单投共 3 次，实战确认其中 1～2 次在失衡内。在工作台把「单投轮可调毁伤（1次）」的失衡开关打开，两轮失衡内的毁伤就从 4 次变为 5 次，全程仍为 9 次。单轮参考轴同样保留这个开关。

毁伤的具体命中帧没有记录。参考轴把失衡外毁伤记在准备阶段，失衡内毁伤记在对应轮的投枪后，保留观测到的总数和失衡分布。每轮末次动作是「此愿」，按此排列能在轴内结清烬痕。自定义轴若在最后一次结算之后还有命中，应保留未结清部分。新构建的「整备」改变了旗令转愿核的时机，此变化对实际循环用时尚待实测。

## 专属机制与建模假设

| 来源 | 条件和计算口径 |
| --- | --- |
| 核心·锐化 | 招式使用防御倍率。初始暴伤每 1% 转为 0.35% 初始暴击率；战斗中获得的普通暴伤不参与转换。基础锐暴伤害 150%。先判一次暴击，暴击率超过 100% 的部分再判一次锐暴，200% 达到两次判定上限。两次触发各乘一次 `1 + 锐暴伤害`。 |
| 核心·极昼 / 支援突击 | 极昼在接战、强化特殊技或投枪时开启。核心 F 提供 40% 暴击率和 20% 无视防御。艾尔妲和林德薇恩的支援突击获得 20% 伤害加成，常规准备段采用艾尔妲的「不灭热忱」。 |
| 额外能力·领袖之证 | 队伍有另一位击破、防护或锋御才能触发。满足条件时众愿一心提供 25% 锐暴伤害，单人默认关闭。 |
| 核心·烬痕 / 烬灭 | 满核心时，投枪、长暗终焉、永昼之炬、此行和此愿各记录实际伤害的 60%，毁伤单独记录 40%。永昼之炬或此愿的终结一击将本招计入后清空储值，直接扣除等量生命。结算使用实际伤害的储值，各乘区已经在原命中上生效。来源只给两招的整招倍率，参考轴以整招命中、终结一击完成为单位。 |
| 一影 | 招式无视 15% 火抗，按目标抗性计算。开场愿火和击败回愿火属于资源效果。 |
| 二影 | 其余锐化招式记录 30%，全部烬痕积攒乘 1.35。满核心时主招式、其余招式、毁伤分别积攒 81%、40.5%、54%。 |
| 三、五影 | 各技能等级分别 +2。按仓库约定，工作台输入最终技能等级。 |
| 四影 | 伤害 +10%。进场首次投枪后的下一个永昼之炬或此愿，自己的积攒乘数由 1.35 提至 2.00。这次加成只作用于该招新积攒的烬痕。 |
| 六影 | 招式额外无视 15% 防御。此愿结算后，特殊永昼之炬造成零直伤，只复制刚才此愿自身新积攒量的 80%，并单独引爆一次。新构建入场额外给予一次整备。 |
| 专武·灼息 | 精1～精5常驻暴击率 20%～28%。强化特殊技或接战后，火属性伤害提升 20%～32%，另有独立的火属性锐化增伤 10%～16%，持续 25 秒。同一来源刷新持续时间。 |

## 验收边界

- 无锐暴增益时，暴击率依次取 0%、50%、100%、150%、200%，单次锐化伤害的期望乘数依次为 1、1.75、2.5、4.375、6.25。
- 默认两轮轴的斩棘每段各计 6 次。毁伤按独立行引用，合计 9 次。烬痕积攒须分别使用每击实际命中的失衡状态。
- 同一招永昼之炬或此愿可打出多段。当前快照只有整招倍率，无法单凭它推导最后一击单独伤害及中断前的命中数。
- 该轴接受全部招式和毁伤均命中的前提，不模拟愿火、旗令、愿核、喧响和失衡条随时间变化，也不预测队友支援与触发时间。
