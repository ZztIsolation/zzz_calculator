本专题只记录佩洛伊斯的来源、当前目录结构和已确定的直伤快照边界。通用数据与事件规则见[建模说明](modeling.md)，制作经验见[角色指南](character-authoring-guide.md)。

## 来源与数据边界

- [官方角色页](https://baike.mihoyo.com/zzz/wiki/content/1958/detail?mhy_presentation_style=fullscreen)：条目修订 `1789136408`，2026-09-19 获取；基础面板、技能 Lv.1-12、核心初始/A-F 和已公开影画优先使用。
- [Gachabase 正式版 3.0.0 / 16735318](https://zzz.gachabase.net/agents/1551/pyrois/release/3.0.0/16735318?lang=chs)：只用于固定正式版技能资料和补充等级交叉核对，不覆盖官方更新说明。
- [Honey Hunter](https://zzz.honeyhunterworld.com/1551-char/?lang=CN)、[支援技能表](https://zzz.honeyhunterworld.com/1551-char/?lang=CHT) 和 [Fandom](https://zenless-zone-zero.fandom.com/wiki/Pyrois)：用于 Lv.13-16 显式值和固定正式版数据的交叉核对；没有从 Lv.1-12 猜等差增长。
- `tests/fixtures/pyrois-source-values.json` 保存 40 行逐级核对值。三处已知来源差异继续保留：余晖第三段 Lv.6 为 402.2%（数据库 402.3%）、重睹天日 Lv.3 为 400.1%（数据库 400.2%）、万军诛绝 Lv.11 失衡倍率为 398.7%（数据库 389.7%）。

60级初始攻击力为849、暴击率为5%；核心F另加75基础攻击力和14.4%暴击率。能量自动回复使用项目存储口径120，不能把耀斑能量效率混入该面板字段。六影未公开或无法确认的效果不擅自补值。

## 四分支效果

| 终结技 | Lv.12本体 | 核心成长的附加效果 |
| --- | ---: | --- |
| 万军诛绝 | 1733% | 失衡目标上的终结技暴击伤害 +40% |
| 凯旋坦途 | 1071.4% | 造成的伤害提升40% |
| 无拘剑势 | 1946.8% | 追加900%攻击力倍率，合计2846.8% |
| 永陷幽囚 | 1994.7% | 追加2250%攻击力倍率，合计4244.7% |

四个分支效果均属于 `agent:pyrois.corePassive`。左右追加值是对应终结技的
`skillMultiplierBonus`，不是额外易伤、异常或紊乱。当前直伤快照假设左右目标条件已满足；不模拟日珥、喧响值、能量资源、持续时间或失衡时间轴。

核心被动的可见描述保留四个分支的触发、作用对象和1-7档数值；额外能力默认启用，保留官方“队伍中存在击破或支援角色”的条件。旧版 `agent:pyrois.skill.mirage`、`sunflare` 和 `contamination` 选择会迁移到核心被动，当前目录不再提供角色技能来源 Buff。

## 当前技能组与管理员默认

当前 `data/agents.json` 中的五个技能组如下：

| 技能组显示名 | 实际子事件 | 是否自动含强袭训令 |
| --- | --- | --- |
| 天光三＋四段(长按普攻) | 天光 `hit_3`、`hit_4` | 否 |
| 上分支大招 | 万军诛绝本体 | 否 |
| 下分支大招 | 凯旋坦途本体 | 否 |
| 左分支大招 | 无拘剑势本体 | 否 |
| 右分支大招 | 永陷幽囚本体 | 否 |

四个大招组的 ID 仍带有历史性的 `_with_directive` 后缀，但当前组事件展开结果只包含对应终结技本体；后缀不能被解释为自动追加强袭训令。`特殊技：强袭训令` 是独立的 `special_assault_directive` 招式，若未来需要表达“本体+训令”，必须在组事件中显式加入并单独验证技能等级和计数。

当前管理员默认方案是“3天光2连携2大招”：

1. 天光三＋四段技能组 ×3，失衡；
2. 连携技：行军仪仗 `chain_marching_regalia` ×2，失衡；
3. 强化特殊技：日华本体 ×1，失衡；
4. 上分支大招组 ×1，失衡；
5. 右分支大招组 ×1，失衡。

目录当前没有额外的影画默认变体；用户指定的技能等级是最终等级，不能再次自动加影画等级。默认方案只是可操作的伤害快照，不代表资源足够、行动时间或实际循环模拟。

## 装备与兼容边界

日冕遗蜕的通用20%暴击率对强攻角色生效；以太抗性无视通过 `requirement.agentIds: ["pyrois"]` 限制在佩洛伊斯。空白名单/未配置不额外限制，非法非数组输入由维护校验拒绝。

核心成长、Buff选择器和维护页读取同一套核心成长表。目录目前要求核心被动四分支统一选用，不应通过旧的分支Buff ID建立多个可独立关闭的伪选项。Enka 展柜还需要单独的头像映射：角色资料存在不等于 `1551` 已可导入；映射由 [data/enka_zzz_mapping.json](../data/enka_zzz_mapping.json) 和 [entity-mapping.js](../core/enka-import/entity-mapping.js)共同决定。
