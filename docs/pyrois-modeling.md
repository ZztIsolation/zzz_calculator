# 佩洛伊斯建模依据

此模型计算用户指定状态快照下的攻击力直伤，不模拟喧响值、日珥、动作时长或失衡时间轴。四种终结技可以分别添加和计数；四个分支效果统一归入核心被动，额外能力默认启用。

## 来源与数据边界

- [官方角色页](https://baike.mihoyo.com/zzz/wiki/content/1958/detail?mhy_presentation_style=fullscreen)：页面版本 `1789136408`，2026-09-19 获取。基础面板、技能 Lv.1–12、核心初始/A–F、公开影画优先使用该页。
- [Gachabase 正式版 3.0.0 / 16735318](https://zzz.gachabase.net/agents/1551/pyrois/release/3.0.0/16735318?lang=chs)：固定正式版数据，只用技能数据与补充等级核对，不覆盖官方更新的影画四说明。
- [Honey Hunter 技能表](https://zzz.honeyhunterworld.com/1551-char/?lang=CN)、[支援技能表](https://zzz.honeyhunterworld.com/1551-char/?lang=CHT)、[Fandom 技能表](https://zenless-zone-zero.fandom.com/wiki/Pyrois)：Lv.13–16 显式数值与固定正式版 skill_data 交叉核对。未从 Lv.1–12 猜测等差增长。
- `tests/fixtures/pyrois-source-values.json` 保存 40 行官方 Lv.1–12 和补充 Lv.13–16 的核对值。零散攻略仅帮助理解连招，不作为伤害数值来源。

已发现并保留的官方差异：余晖第三段 Lv.6 为 402.2%（数据库 402.3%）；重睹天日 Lv.3 为 400.1%（数据库 400.2%）；万军诛绝 Lv.11 失衡倍率为 398.7%（数据库 389.7%）。这些差异不标记为“来源完全一致”，也不擅自纠正。

60 级初始攻击力 849、暴击率 5%；核心 F 另加 75 基础攻击力和 14.4% 暴击率。能量自动回复沿用项目存储口径 120，不把耀斑的能量获得效率混入该面板项。

## 四分支与附带伤害

| 终结技 | Lv.12 本体 | 条件效果（核心 F） |
| --- | ---: | --- |
| 万军诛绝 | 1733% | 终结技命中失衡敌人时暴击伤害 +40% |
| 凯旋坦途 | 1071.4% | 造成的伤害提升 40% |
| 无拘剑势 | 1946.8% | 追加 900% 攻击力倍率，合计 2846.8% |
| 永陷幽囚 | 1994.7% | 追加 2250% 攻击力倍率，合计 4244.7% |

四个分支效果均通过核心被动提供；左右追加倍率通过 `skillMultiplierBonus` 精确绑定对应终结技，不是额外易伤、异常或紊乱。按直伤快照口径，使用无拘剑势或永陷幽囚时默认对应目标条件已满足；不模拟日珥、喧响值、持续时间和失衡时间轴。

强袭训令独立使用特殊技等级、普通特殊技类型，无 `exSpecial` 或 `assistAttack` 标签；Lv.12 为 166.4%。四个“含强袭训令”终结技组各包含本体与一次训令，不再手动追加。日华提供含/不含训令两种组，用于表达 2.5 秒冷却导致的触发差别。模型不判断实战资源是否足够释放。

## 等级、装备与兼容

默认示例为零影、核心 F、技能 Lv.12、一次非失衡天光三＋四段。管理员默认配置在三影采用最终技能 Lv.14、五影及以上采用 Lv.16；用户指定的技能等级就是最终等级，计算内核不再额外加级。

影画一加 8% 暴击率；二影仅影响资源循环；四影护盾和失衡值加成不转成增伤。六影官方未揭示，工作台显示独有效果未计入，已知五影效果继续保留。

日冕遗蜕的通用 20% 暴击率仍对强攻角色生效，以太抗性无视增加 `requirement.agentIds: ["pyrois"]` 限制。空白名单/未配置不增加限制；非法非数组输入不生效且维护校验拒绝。已有其他配置的语义不变。

核心被动与招式通过现有 Buff/技能组存储恢复。核心成长的效果在计算、Buff 选择器和维护界面使用同一成长表；旧版三个分支技能 Buff ID 会归一到核心被动。

## 验证入口

`npm run test:pyrois-damage`：官方逐级数据、条件开关、独立伤害公式、技能组计数与等级、音擎限制、普通/白盒/编译/dense/固定套装/Node Worker 优化器及驱动盘分析。

`npm run test:webapp`：默认配置、四分支保存恢复、Buff 核心成长显示、影画最终等级、维护白名单编辑。
