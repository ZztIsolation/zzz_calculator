## 面板与核心

60级、未加核心节点的角色白值：生命8373、攻击671、防御622、冲击120、精通93、掌控90。
A/C/E各增加12点基础掌控，B/D/F各增加25点基础攻击。满核心白值攻击746、掌控126。

| 项目 | 初始 / A / B / C / D / E / F |
| --- | --- |
| 核心精通，局内固定加值 | 60 / 70 / 80 / 90 / 100 / 110 / 120 |
| 蓄力普攻或强化特殊技命中后全队普通增伤 | 13 / 15 / 17 / 19 / 21 / 23 / 25% |
| 自身异常积蓄效率，仅说明 | 17 / 20 / 23 / 26 / 29 / 32 / 35% |
| 自身失衡值加成，仅说明 | 11 / 12.5 / 14 / 15.5 / 17 / 18.5 / 20% |

冲击力转换自动读取局外面板：`max(初始异常掌控 - 110, 0)`，输出固定冲击力。
原文没有规定上限或取整，采用未取整数值；局内临时掌控不进入转换。
例如初始掌控211时，转换增加101点冲击力，基础120时合计221。

普通增伤按效果覆盖率计算；核心精通和初始掌控转换不设覆盖率。
额外能力的踉跄增加30个百分点失衡易伤，二影再增加30个百分点。
一影全属性抗性降低18%，四影固定精通增加40。帷幕攻击50点由独立终结技来源Buff提供，默认关闭。

## 颤音异放

异放事件可以选择1～4层颤音，以及六影1～4层颤音改。
常规颤音默认4层；六影方案只允许在影画6时计算。

| 原异常属性 | 核心基础比例 | 六影颤音改基础比例 |
| --- | --- | --- |
| 以太 | 720% | 800% |
| 电 | 360% | 400% |
| 火 | 900% | 1000% |
| 物理 | 63% | 70% |
| 冰 | 90% | 100% |
| 风 | 36% | 40% |

采用公式：`原异常单次倍率 × 属性比例 × (1 + 颤音层数 × 每层提升)`。
常规每层25%，二影及以上核心颤音每层35%；四层分别乘2和2.4。
六影颤音改仍每层25%，二影条款只修饰核心被动中的颤音异放。
“比例额外提升”的乘法解释作为明确项目假设保留，尚未通过独立游戏实测确认。
不要把720%与四层100%直接相加，也不要再额外乘触发者南宫羽的精通。

异放使用原异常来源面板。自身侵蚀用当前南宫羽实时面板；冰底等外部来源需要选择实际来源并保存冻结快照。
优化期间外部快照不随南宫羽换盘更新；当前模型不进行全队联合优化或积蓄贡献自动加权。

倍率方案常量节点支持七个`cinemaValues`，在事件准备时按当前影画物化。
普通、compiled、dense和固定套装评分使用同一物化公式树；这是实现接入方式，不代表各路径已经数值测试验收。
维护页可以编辑常量的影画成长和方案最低影画。

## 技能与默认目标

技能1～16级由源数据明确的`main`和`growth`生成，两项单位都除以100后保存为百分数。
三段协同蓄力总伤害放在独立招式，避免普通三段总倍率重复加入第三段。
提供纯三段普攻、纯三段蓄力两个组；连携与终结技独立选择。
3/5影成长保留在描述；工作台技能等级输入是最终等级，不额外自动加2。

默认目标仅一发「自身侵蚀异放：4层颤音」，不是南宫羽全流程输出或雅南柚队伍评分。
默认不隐含添加20跳侵蚀、普通紊乱或两次极性紊乱。
盘子候选默认法厄同之歌，4号精通/攻击、5号以太/穿透/攻击、6号掌控/攻击；这是可搜索候选，不是整个队伍的最优推荐。
霓虹妄想复用原有数值，加入角色关联；头像复用已有本地资源，展柜映射加入1511。
