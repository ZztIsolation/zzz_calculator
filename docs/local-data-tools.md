# 本地数据工具

## 扫描翻页

游戏 3.3 起点击背包最下面一行不再翻页。Scanner 1.0.49 默认的“点击底行”翻页会读到重复行，由重复保护以 `duplicate_guard` 停止。

计算器的扫描请求默认带 `rowAdvanceMode: "wheel"`，使用 Scanner 自带的滚轮翻页并逐次核对位移。调用方显式提供 `rowAdvanceMode` 时仍保留该设置。

历史用户反馈在 1920×1080 下成功扫描 512 件；这不是本次分支的真实游戏验收，也不代表已覆盖所有分辨率。

## 本地解析保护

核对日期：2026-10-22。本节只说明本地数据读取保护；源码实现和隔离测试不代表日常服务已更新。

当前保护库存 localStorage fallback、构筑选择、账号选择和优化设置；这些读取区分“键不存在”和“JSON 解析失败”。
只有不存在时使用默认值；解析失败抛错、保留原字符串并阻止相关保存。
发生上述 JSON 解析失败时，页面提供“导出原始内容”，启动失败时也可进入完整备份恢复；IndexedDB、导入锁或事务恢复失败使用刷新/重试路径。
扫描器偏好和维护草稿继续使用各自的读取与恢复逻辑，不属于本保护范围。
该保护不意味着用户现有数据损坏，也不负责自动猜测、修补损坏内容。

## 任务与账号隔离

账号的新建、改名、切换、删除共用执行中状态。执行期间会禁用重复操作；失败时显示具体原因，
保留名称草稿或删除确认，账号列表的旧加载结果也不能覆盖后发操作。

工作台开始优化前记录当前账号、角色和请求代号。切换账号、角色或离开工作台时，终止旧 Worker
并结算等待中的请求；已经排队的成功、错误、预估和进度消息都必须检查任务身份。只有当前任务的完整结果
可自动选中方案。临时 Top 10 只能查看，不能保存方案或锁定驱动盘；完整结果到达后才恢复这些操作。

优化 Worker 的目录数据同时带内容指纹，目录对象复用但内容变化时必须重新发送。取消、错误、重置和
Worker 终止都会清理任务池、结算等待中的 Promise，并丢弃旧任务的回调。

## 仓库与选盘分页

驱动盘仓库每页数量可选 5 / 10 / 20 / 50 张（默认 5，减轻低配电脑一次渲染的压力；记住上次选择，键 `zzz-calculator.webapp.discs.pageSize.v2`）；公共选盘组件及关闭使用限制界面时的旧选盘弹窗每页显示 20 张盘。
选盘默认按当前角色重要副词条的有效条数（含强化次数）从多到少排序，可切换为按套装；角色未配置重要副词条时只按套装排序。
筛选在完整库存上进行，匹配结果变化回到第一页；显示匹配总量和当前页码。
分页仅截取渲染数组，优化候选和当前账号的批量导出不受页面、搜索或筛选限制。

## 完整个人备份

入口为“设置 → 完整个人备份”。格式为 `zzz-calculator-personal-backup`，版本为 `1`。
备份包含完整库存文档和本应用浏览器设置的原始字符串，覆盖全部账号、驱动盘、套装预设、来源、
专属/排除、穿戴关系、绑定和事务历史，以及各账号角色计算配置、音擎、队友、Buff、事件、敌人和选盘记录。
不包含项目目录中的角色文件、游戏文件、扫描器安装文件，也不读取无关网站存储。
其他独立的实验性配置键保持原值，永远不进入完整备份。

完整恢复采用整份替换，不合并账号。选择文件后会预览当前和目标的账号数、盘数、套装数、设置数及账号名称；
先下载恢复前副本并勾选确认后才允许写入。预览后个人数据发生变化时拒绝应用，恢复前应关闭其他计算器标签页。

恢复复用既有全局写入锁和库存记录：先把旧库存与原始设置写入 `personalDataRestore` 临时日志，再写目标设置及最终库存。
失败会回滚，刷新启动时先恢复中断日志，再执行原驱动盘和 Enka 事务恢复；不变更 IndexedDB 数据库、object store 或版本。
坏 fallback 只有在显式恢复且原始字符串仍一致时才可替换，恢复前副本保留原坏字符串。

## 撤销普通导入

入口为“驱动盘 → 撤销上次导入”。只保留当前账号最近一次成功 JSON / 扫描导入的撤销记录，
使用既有导入事务的前后快照构造反向事务。预览和确认都会检查数据是否变化。
相关驱动盘被强化、删除，或当前账号配置、套装引用发生变化时拒绝撤销；无关的新盘可以保留。
配置冲突检查按整个账号保守处理，因此某些与该次导入无关的配置编辑也会要求人工处理。
撤销成功后清除本次撤销记录，不提供多步历史回退。

失败回滚、中断恢复和 Enka 撤销保留原语义。完整备份恢复与普通导入撤销是两个独立操作，完整恢复不会自动执行导入撤销。
