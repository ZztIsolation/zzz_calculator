# 风化、乱流与紊乱建模

状态：现行结算专题。核对日期：2026-10-08；基准提交：`6355fbd310cc5836aff0e78bc3fb46e68a5356f8`。

通用事件、来源快照和维护边界见[建模说明](modeling.md)；本文件只维护风化、乱流、紊乱和维琳娜专属规则。

## 触发关系

- 非风属性异常A与非风属性异常B连续触发时结算紊乱，紊乱基于先触发的A。
- 风化与任意非风属性异常连续触发时结算乱流，不结算紊乱。乱流基于非风属性异常，顺序只通过该异常剩余时间影响 `T`。
- 风化仍可作为普通属性异常事件。风属性角色不能添加乱流或紊乱；紊乱目录不能选择风化。

## 正式事件结构

乱流只保存非风基底异常、已流逝时间、次数和失衡状态：

```json
{
  "kind": "anomaly",
  "settlementType": "turbulence",
  "anomalyEffect": "burn",
  "elapsedSeconds": 0,
  "count": 1,
  "stunned": true
}
```

它不保存风化来源、第二异常、来源面板快照、剩余时间、待确认倍率或特殊形态。正式伤害使用当前非风属性角色的面板；维琳娜作为队友只通过已选择的队友Buff提供乱流倍率、乱流增伤和抗性无视。维琳娜界面展示说明，但不生成要求她自身面板的正式乱流事件。异常代理人的完整组队伤害仍不在本模型内。

维琳娜的异放是另一种 `settlementType: "release"`。她通过 `releaseSource` 选择 `micro_vortex`、`broad_vortex` 或 `ultimate_wind`，强制使用风化基底；保存后的维琳娜事件不再携带通用 `triggerActorRef`/`anomalySource` 字段。通用Aria/Vivian双来源模型不因此删除。当前目录的管理员默认是“单次风化”，不是异放；已有自定义直伤和异放配置不得被新默认覆盖。

## 乱流倍率与时间

`T` 是应用持续时间延长后的非风异常剩余时间。新事件 `elapsedSeconds=0`，默认吃满 `floor(T)`；火和以太按0.5秒归一化，物理、冰、电和烈霜按1秒归一化。事件存储不得按基础时长截断，因为最终计算可能叠加持续时间延长。

| 基底 | 固定倍率 | 时间项 |
| --- | ---: | ---: |
| 强击 | 800% | `floor(T) × 7.5%` |
| 碎冰 | 1300% | `floor(T) × 7.5%` |
| 灼烧 | 900% | `floor(T / 0.5) × 50%` |
| 感电 | 650% | `floor(T) × 125%` |
| 侵蚀 | 650% | `floor(T / 0.5) × 62.5%` |
| 烈霜 | 0% | `floor(T) × 75%` |

倍率目录是版本化的已确认资料；不再使用 pending 倍率或事件内手填固定倍率。时间步长从目录 `tickIntervalSeconds` 读取，未知旧异常回退0.5秒。

## 乘区与来源边界

乱流公式为：

`攻击区 × 乱流倍率 × 增伤区 × 异常精通区 × 防御区 × 抗性区 × 异常减易伤区 × 失衡易伤区 × 等级区 ×（异常增伤区 + 乱流增伤区）× 异常暴击区 × 异常爆伤区`

紊乱只使用紊乱倍率、紊乱增伤和通用基础乘区，不读取通用异常增伤或异常暴击/爆伤。乱流按基底属性读取属性伤害和抗性，火乱流不能读取风属性伤害。

维琳娜核心、专武、影画和异放来源规则必须分别标明作用范围。六影“风化重施增伤”使用运行时 `0%-40%` 输入，默认40%，存为 `anomalyDamageBonus`，只命中属性异常 `wind_corrosion`；与C2和专武风化增伤相加，不作用于普通直伤、风直伤易伤、乱流、紊乱、异放或耀变。释放事件继承来源Buff时排除这条动态增伤。

维琳娜的初始能量自动回复转换按每个候选盘的最终局外面板计算；不读取局内能量回复，也不能在候选面板出现前预编译成零值。转换后的异常掌控再进入异常精通和异放评价。支持的单调阶梯公式可进入dense/固定评分，上界不安全或条件不支持时回退通用评分。

## 队友 Buff

维琳娜队友目录提供四项可选Buff：F级核心固定 `+150%` 乱流倍率，额外能力 `+10%` 乱流增伤，1影 `20%` 全属性抗性无视，2影 `+15%` 乱流增伤。核心队友Buff固定F级，不跟随当前维琳娜核心等级。

## 当前维护和验证

维护目录是默认配置的事实来源；维护编辑后应保存、刷新并重新打开确认，不可让旧迁移入口自动恢复“单次广域气旋异放”。

- `npm run test:turbulence-damage`：乱流/紊乱倍率、时间、属性过滤、来源继承和跨路径结果。
- `npm run test:velina-damage`、`npm run test:velina-c6-damage`：维琳娜公式、异放来源、六影作用范围。
- `npm run test:velina-optimizer`：候选面板、快速评分、边界和严格Top 10。
- `npm run test:maintenance-api`、`npm run test:layout`：维护保存、默认循环布局和实际容器表现。
