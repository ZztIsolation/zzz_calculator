# 风化、乱流与维琳娜建模

风化属于风属性异常，乱流是独立的异常结算类型。乱流不会复用普通紊乱的结算桶，也不会清除风化状态。

风化事件保存风化触发者和风化异常基底。乱流事件保存风化来源、第二异常来源、第二异常元素、剩余时间和版本化倍率状态。乱流的结算元素来自第二异常，伤害归属来自风化触发者；两个来源的攻击力、异常精通、穿透和 Buff 不会先做平均。

乱流倍率目录保存固定倍率、剩余时间系数、取整方式、资料版本、来源和置信度。倍率状态为 `pending` 时，核心拒绝计算并返回缺少已确认版本化资料的错误。事件显式提供 `baseMultiplier` 时可用于测试或已经完成来源确认的配置。

异常 Buff 的默认目标按结算类型分桶：属性异常增伤作用于风化、乱流、异放和耀变；普通紊乱继续使用独立的紊乱增伤；乱流增伤和异放增伤只作用于各自结算。精确指定属性异常的规则不会自动扩展到乱流。属性伤害加成按实际结算元素读取，因此火属性加成可以作用于火乱流，风属性加成不会作用于火乱流。

风化系数属于直伤易伤区，只作用于风属性直伤和浸染属性直伤，不作用于风化、乱流、异放、普通紊乱或耀变。

维琳娜的核心等级数据来自官方角色词条，保存乱流强化、微域气旋异放和广域气旋异放倍率；终结技的固定 680% 风属性异放和气旋异放使用独立 `release` 事件。风华、风蚀、气旋持续时间和乱流冷却暂不自动模拟，由事件条件或次数表达。
