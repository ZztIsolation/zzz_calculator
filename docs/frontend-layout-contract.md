# 前端布局契约

状态：现行 Vue/Naive UI 布局规则。核对日期：2026-10-08；基准提交：`6355fbd310cc5836aff0e78bc3fb46e68a5356f8`。

目标不是让所有内容保持单行，而是在真实可用宽度内完整、可操作地呈现业务文字和控件。保存、草稿和冲突行为见[长期回归契约](regression-contract.md#维护功能)。

## 共享布局类

- `ui-layout-scope` 或 `data-layout-surface` 建立 `inline-size` 容器；弹窗、抽屉、主从面板和嵌套编辑器按这个容器响应。
- `ui-master-detail` 使用 `280-340px + 剩余空间`；容器不足760px时自动堆叠。
- `ui-field-grid` 使用 `repeat(auto-fit, minmax(min(100%, 144px), 1fr))`；comfortable变体基础宽度180px。
- `ui-field--wide` 占两个轨道，`ui-field--full` 占整行；窄容器不得产生隐式溢出轨道。
- `ui-field`、`data-layout-field`、`metric`、`maintenance-field`、`custom-field` 和 `compact-field` 继承字段收缩、标签换行和Naive UI控件宽度规则。

## 表单和内容

- 表单标签、当前值、校验错误、状态提示和命令按钮不得使用隐藏裁切维持单行。中文标签可自然换行；不可分割长文本使用 `overflow-wrap:anywhere`。
- 输入框、数值步进器和选择器必须留在所属字段边界内，字段和网格子项设置 `min-width:0`。
- 密集列表可用省略号，但必须通过 `title`或tooltip提供完整名称；表单标签和关键结果不得省略。
- 技能组定义、技能行、效果规则、计算事件、Buff修饰器和Core/Potential成长表各自保持稳定字段布局，不能按动态字段数量猜列数。
- 维护表单允许读取技术ID进行审计，但用户操作使用中文名称和可读关联。自动来源不重复要求管理员输入。

## 默认循环与维护弹窗

角色表单只展示管理员默认循环摘要；完整配置在影画页签的主从弹窗内编辑：左侧是方案、目标事件列表和事件摘要，右侧是当前事件详情。长事件列表和详情各自滚动，页脚的取消/应用始终可见。

弹窗打开使用JSON兼容草稿；取消不改角色草稿，应用后才标记变更，角色级保存才写入API。复制影画方案要重建事件ID并重映射选中目标；删除事件保留有效目标，最后一个事件不可删除。

默认循环中静态只读值使用正常文本色，不用低对比度禁用控件伪装只读。管理员模式按目录提供的 `stunned` 和事件计数展示；普通用户模式仍可逐事件调整允许的字段。

## 响应式与滚动

页面顶栏、整页工作台列数等由浏览器宽度决定的结构可用 `@media`。弹窗、抽屉、卡片、侧栏和维护编辑器内部必须用 `@container`或内容驱动网格，不能用viewport宽度猜自身可用宽度。

表格、图表、导航条和事件列表可在明确的局部容器滚动，但横向溢出不能传递到页面或弹窗外层。添加复杂表单时给最外层添加`data-layout-surface`，给关键字段添加`data-layout-field`。

吸顶元素统一以 `--app-topbar-height` 为偏移；顶栏在窄屏换行时必须同步更新该变量，吸顶内容不得压住顶栏。

## 工作台分栏

行为约定（2026-10-20新增）：

- 宽于1280px：左侧输入（角色、音擎、Buff、计算设置、敌方）、中间优化与驱动盘、右侧结果三栏等高吸顶，各自独立滚动，底边对齐；页面不再出现纵向滚动。
- 右栏依次为当前结果数字、面板、白盒；结果数字在右栏内吸顶。
- 981–1280px：左、中两栏；结果数字拆为整行吸顶条置于最上方，面板与白盒移到驱动盘之后。左栏仍吸顶并让出结果条高度。
- 980px及以下：单栏，顺序为结果条、优化与驱动盘、左侧配置、面板、白盒；只有结果条吸顶。
- 按钮层级：“开始优化”是中栏唯一的实心主按钮；“选择 Buff / 编辑事件 / 计算配置”三个配置入口共用同一浅色强调样式。
- “局内 Buff”默认收起，标题栏显示已启用数量与“选择 Buff”按钮；错误提示始终可见。方案来源使用主题分段滑块，优化结果无结果时禁用。

## Buff 选择弹窗

- 弹窗宽度固定为 `min(1280px, calc(100vw - 16px))`，高度固定为视口高度减 32px；切换页签不改变外框尺寸，列表内部滚动，取消/应用始终可见。
- 每行显示一个 Buff；已选默认展开、未选默认收起，可单独展开详情，摘要通过 title 保留完整效果和说明。
- 打开弹窗或切换页签时已选项置顶；勾选时不立即改变顺序，页签显示各类已选数量。
- 按实际效果提供筛选，队友音擎额外按特性筛选；切换页签或重新打开时重置筛选。适用技能超过三个时可折叠查看。
- 展开、筛选和排序只改变展示；取消丢弃草稿，应用成功后才保存选择和参数。

## 深色模式与颜色变量

核对日期：2026-10-23；基于 PR #90 与 main `23664e9` 的主题修订。

- 顶栏账号信息左侧提供主题按钮，以电脑、太阳、月亮表示跟随系统、浅色、深色；点击按此顺序循环。提示语与无障碍名称同时说明当前模式与下一模式，键盘焦点必须可见。
- 默认跟随系统；偏好保存在浏览器本地 `zzz-calculator.webapp.theme.v1`，跨刷新保留，不绑定账号。无效值按跟随系统处理；存储不可用时本次切换仍生效。
- 手动浅色/深色写入 `<html data-theme>`，优先于系统；跟随系统时移除属性，由 `prefers-color-scheme` 和一次系统监听同步 CSS 与 Naive UI。
- 挂载前同步恢复偏好，Naive UI 深色主题同步导入；不单独下载主题或等待加载超时。这会减少挂载时主题不一致，但不保证脚本执行前完全没有闪烁，也不宣称首屏减包收益。
- 组件背景、文字、边框及状态色使用 `tokens.css` 的语义变量；Naive UI 配置集中在 `webapp/src/runtime/theme-overrides.ts`，共享字体、圆角和尺寸。保留固定品牌/图表配色时仍需验证两种主题的可读性。
- 重要属性名称和命中副词条保留既有橙色高亮，普通数值保持中性；主题切换不改变计算、排序或角色配置。
- 验收入口：`webapp/src/runtime/theme.test.ts`、`webapp/src/App.test.ts` 与 `webapp/e2e/theme.e2e.ts`。覆盖真实点击、键盘、系统变化、刷新、路由和已打开弹窗，以及桌面和窄屏下的颜色对比与控件可达性。

## 工作台驱动盘布局

行为约定（2026-10-13新增、2026-10-15修订；实际验收见变更日志）：

- 优化结果、自选驱动盘、已有套装三种工作台视图统一按两列三行展示槽位：上排 `1、6`，中排 `2、5`，下排 `3、4`。从左上向下，再沿逆时针方向依次为 1 至 6 号位。
- 窄屏仍保持这组槽位关系，不改成单列或按数字逐行排列。卡片内部按实际容器宽度压缩、换行；卡片、锁定控件和词条不得越出自身边界，也不得造成页面横向滚动。
- 优化结果方案选择区在方案数字选择器左侧展示“一键锁定”按钮，整套属于当前角色时切换为可点击的“一键解锁”。按钮处理当前选中方案，具体预约、冲突确认、缺盘和已锁状态遵循[驱动盘一键锁定约定](regression-contract.md#驱动盘一键锁定)。
- 槽位顺序仅改变展示，盘 ID、实际槽位、自选配置、已有套装引用和优化结果排序保持原有语义。

## 自动验收

运行 `npm run test:layout`。Playwright在桌面、125%缩放桌面、390x844及更窄移动端检查：

- 页面和受保护容器无意外横向滚动；
- 维护字段、事件摘要和控件没有越过最近容器；
- 标签的 `scrollWidth/scrollHeight`不超过可见尺寸；
- Naive UI输入、数值和选择控件没有越界；
- 默认循环弹窗可以访问全部事件，取消/应用页脚可见；
- `已流逝秒数`和长中文压力文案完整显示；
- 保存、刷新和重新打开后字段仍是预期值。

具体浏览器场景维护在 [layout.e2e.ts](../webapp/e2e/layout.e2e.ts) 和 [agent-maintenance.e2e.ts](../webapp/e2e/agent-maintenance.e2e.ts)。

### 工作台代码组织

- 计算页各栏共用的区块样式（`.workbench-surface`、`.workbench-section`、吸顶栏等）在全局 `webapp/src/styles/workbench.css`，页面与拆出的子组件共用。
- 展开/收起统一用 `ExpandToggle`（蓝色箭头＋可选文字，展开后翻转），放在被展开内容的上方或标题行，展开后位置不变。左栏的事件摘要和已启用 Buff 用 `.workbench-inset-list`（每行左名称、右数值），数量用 `.workbench-count-badge` 小徽标，不用换行乱排的圆角标签。
